# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this folder is

A GTM workspace for NotLinear (notlinear.ai), which trains non-technical teams and individuals to use AI at work. It holds markdown only, with no code, build, lint, or test commands, and it isn't a git repository.

## Business context

Read the relevant files in `business-context/` before doing GTM, marketing, or sales work. `README.md` there indexes them.

- Use `offers.md` for offers, prices, and dates, `proof-points.md` for claims and customer results, and `positioning.md` for messaging and voice.
- `gaps-and-questions.md` lists known site inconsistencies and open business questions.

## Working with these files

- Keep the labels: **Stated** means the site or a Maven page says it, and **Inferred** means it's an unconfirmed reading of the evidence. Don't present inferred audience or competitor points as fact.
- The files are a snapshot from 5 November 2026. Check dates, prices, and ratings against the [site](https://www.notlinear.ai/) and [Maven](https://maven.com/pietro-montaldo) before reusing them.
- Student numbers conflict: 5,000+ on the homepage and 20k+ on Maven. Don't use either in new copy without checking which is right.
- Performance claims are NotLinear's own and haven't been independently verified.
